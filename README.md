# Code Archmage

本地、只读的源码拆解工具。面向「刷过题、第一次面对工程代码不知道从哪读」的计算机系学生。

代码不出本机：解析和索引都在你电脑上完成，服务只监听 `127.0.0.1`。不编辑、不运行、不调试，只用来读。

当前仅支持 **Python**。

## 能做什么

打开一个本地 Python 仓库后，可以：

- 浏览文件树和当前文件的符号大纲
- 在只读代码视图里点调用，跳到定义
- 按符号名搜索整个项目
- 看当前符号的一层调用图（谁调用了它、它调用了谁）
- 「剥洋葱」：把调用链展平成从入口到当前符号的路径
- 选中符号后向 LLM 提问；引擎会自动拼上函数体、调用关系等上下文
- 按需生成一句话摘要（首次生成后缓存到本地索引库）
- **导读视图**：按 项目 / 模块 / 文件 三级生成中文讲解，讲解与真实代码片段对照，点代码块跳回阅读模式定位

调用关系按函数名匹配，同名函数可能对不上，界面会标明这一点。

## 启动

需要：Python 3.11+、Node.js 22+、[uv](https://docs.astral.sh/uv/)、[pnpm](https://pnpm.io)。

### 1. 安装依赖（只需一次）

```bash
cd engine && uv sync
cd ../web && pnpm install
```

### 2. （可选）配置 LLM

对话和摘要需要 API Key。复制根目录的 `.env.example` 为 `.env` 后填写：

```env
LLM_API_KEY=your-api-key-here
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
```

任何 OpenAI 兼容接口都可以（DeepSeek、智谱、通义、OpenAI、本地 Ollama 等）。不配也能用浏览、跳转、搜索和调用图，只是右侧「对话」和摘要不可用。

DeepSeek 文档里的 `LLM_BASE_URL` 常常写成 `https://api.deepseek.com`（给 OpenAI SDK 用）。本引擎会自动补上 `/v1`；你也可以直接写成 `https://api.deepseek.com/v1`。

引擎按这个顺序找 `.env`：**`--env` 指定的文件** → **被阅读项目根目录** → **当前工作目录** → **本工具仓库根目录**（与 `engine/`、`web/` 同级）。所以把 `.env` 放在本仓库根目录后，用 `uv run --directory engine ...` 启动也能读到。改完 `.env` 后需要重启引擎。

找不到文件、缺了某一项、或 `LLM_API_KEY` 仍是示例占位值，对话面板会分别说明，不会都显示成「未配置」。

### 3. 起两个进程

终端一，启动引擎（把路径换成你要读的 Python 项目）：

```bash
cd /path/to/code_archmage
uv run --directory engine python -m code_archmage /path/to/your/python/project
```

默认端口 `8765`，可加 `--port 8765` 修改。

终端二，启动界面：

```bash
cd /path/to/code_archmage/web
pnpm dev
```

浏览器打开 [http://localhost:5173](http://localhost:5173)。前端会把 `/api` 代理到本机引擎。

### 4. 索引

页面打开后点顶部 **索引**。索引写在被阅读项目下的 `.code_archmage_index/`（已 gitignore），不上传、不进 git。

## 调用图和剥洋葱

两个面板都在右侧。先在左侧文件树打开一个 `.py`，再点左侧 **符号大纲** 里的函数 / 类 / 方法，选中后右侧才会有内容。代码视图里点调用跳到定义，同样会选中那个符号。

### 调用图：看这一层的邻居

适合问「谁在用它、它又用了谁」。

1. 选中符号后，右侧默认就是 **调用图**。
2. 图是三列：左边是调用者（谁调用了当前符号），中间是当前符号，右边是被调用者（当前符号调用了谁）。只画上下游各 **一层**。
3. 点图上的节点，会跳到对应代码，并以它为新的中心重画。可以一层一层点进去。
4. 只有中心、左右都空，说明索引里没找到这一层的调用关系（例如还没人调用它，或它不调别的函数）。

画布可以平移、缩放，节点不能拖。

### 剥洋葱：看从入口到这里的整条链

适合问「程序是怎么走到这个函数的」。

1. 选中你想拆的那个底层符号（越靠里越有用）。
2. 点右侧 **剥洋葱**。
3. 每条路径都是一条从上到下的栈：入口在最上，当前符号在最下并高亮。可能有多条路径（不同入口或不同中间层都会各列一条）。
4. 点路径上的名字，会跳到那一层的代码。配了 LLM 时，当前符号旁边可以生成一句摘要。

链路有上限：向上最多 5 层、每层最多 10 个调用者、总共最多 50 条路径。超出时会提示已截断。

### 调用关系不准时

匹配按函数名，不区分是不是同一个类、同一个文件。项目里如果有多个同名函数，图和链都可能串到别人身上。面板上的提示就是这个意思，以跳进去看源码为准。
